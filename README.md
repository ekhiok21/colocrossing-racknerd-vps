## 实测数据：DC-03 机房晚高峰到底行不行

2026 年 9 月 NodeSeek 上有一份 RackNerd 洛杉矶 1C1G（$21.99/年 档，DC-03/ColoCrossing 机房）的自购实测，闲时和晚高峰各测一轮，是目前这个套餐最细的一份公开数据。作者用的是深圳联通测试点：

- **延迟很稳**：闲时平均 159.9 ms、抖动 0.73 ms、零丢包；晚高峰 163.1 ms，平均只涨 3 ms，全天 0% 丢包。一条没有任何优化的 Cogent 裸路由能做到这个稳定度，说明这一段交接质量高。
- **机房侧出口不虚**：单线程到美国本地目标能跑 796–857 Mbps，晚高峰仍有 705–728 Mbps。
- **问题在跨境段**：晚高峰国内方向单流下载在 3.0–52.3 Mbps 之间乱跳（中位约 18 Mbps），而同一时刻交替拉 Cloudflare 仍稳定在 273–329 Mbps——两头都没问题，掉的是中间那段。闲时单流 118.7 Mbps 的成绩别拿来规划用途。
- **移动绕伦敦**：回程经伦敦再交 CMI，延迟 276 ms，比联通方向多 116 ms。三网回程全是 Cogent 裸路由，没有 CN2 GIA / 9929 / CUII 优化。
- **IP 质量够用但不是全绿**：Netflix 非自制剧完整解锁（Netflix OCA 就在本机房）、OpenAI 可用、YouTube 判 US；5 个可验证邮件黑名单全部未列入；但 proxycheck.io 给出 risk=66 / VPN 标记，风控敏感业务要留意。
- **1 GB 内存确实紧**：961 MB 内存已在用 swap（用掉 150–165 MB），磁盘倒是意外能打——读 812 MB/s、真落盘写 238 MB/s、4K 随机 9,750 IOPS。

作者的结论值得原样记住：「$21.99/年拿到一台联通延迟极稳、磁盘意外能打、能自建邮件、还给 3 TB 流量的美西小鸡；代价是没有 IPv6、联通带宽晚高峰会掉到零头、移动方向绕伦敦。」这份实测没有可用的电信测试点，电信方向没有结论，电信用户请先用官方测速点（lg-lax03.racknerd.com 提供 1GB 测试文件）自行验证。
